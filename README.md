# 🍇 Каталог винограду

Готовий каталог посадкового матеріалу. Відкривається у будь-якому браузері.

## Як відкрити
Двічі клацніть на файл **`index.html`** — каталог відкриється у браузері.

## Ціни
- **Чубуки** — 50 грн
- **Саджанці** — 150 грн

## Можливості каталогу
- Пошук за назвою сорту
- Фільтр за типом (столові / кишмиші)
- Фільтр за кольором (білий, рожевий, червоний, синій)
- Для кожного сорту: термін дозрівання, маса грона та ягоди, смак, морозостійкість
- **Клік по картці** — відкриває вікно з повним описом сорту, усіма характеристиками, цінами та **галереєю фото**
- **Галерея**: кілька фото на сорт, перемикання мініатюрами
- **Клік по фото** у вікні — відкриває фото на весь екран (лайтбокс) з навігацією ◀ ▶ (або стрілки на клавіатурі, Esc — закрити)
- Друк / збереження в PDF: у браузері натисніть **Ctrl+P** (⌘+P на Mac) → "Зберегти як PDF"

## 📁 Де лежать фото — папка на кожен сорт
У папці `images/` є **окрема папка для кожного сорту**. Усередині — фото з простими іменами:

```
images/
  бажена/
    1.jpg   ← головне фото (воно ж мініатюра на картці)
    2.jpg   ← друге фото галереї
    3.jpg   ← третє
  лівія/
    1.jpg
    2.jpg
    ...
```

**Як замінити фото:**
1. Відкрийте папку потрібного сорту, напр. `images/лівія/`.
2. Замініть `1.jpg` своїм головним фото (**збережіть ту саму назву** — `1.jpg`).
3. Додайте ще фото як `2.jpg`, `3.jpg`, … (до `8.jpg`).

Зараз у кожній папці лежать **заглушки** (3 шт. на сорт) з підписом назви сорту й шляхом до файлу — щоб було очевидно, що саме замінювати. Просто перезапишіть їх своїми фотографіями з тими самими іменами.

- `1.jpg` — обовʼязкове головне фото (мініатюра на картці).
- `2.jpg`, `3.jpg` … — додаткові; яких немає, ті просто пропускаються.
- Якщо фото одне — смуга мініатюр у вікні не показується.

> Формат — `.jpg`. Хочете `.png` — перейменуйте фото у `.jpg` (найпростіше) або змініть розширення у функціях `galleryCandidates`/`mainPhoto` у `index.html`.

## Фото з інтернету (стан)
Автоматично з вільного джерела (Wikimedia Commons) вдалося знайти достовірне фото лише для **1 сорту**:

- **Мускат Блу** — лежить як `images/мускат-блу/1.jpg` (ліцензія CC BY-SA 3.0, фото грона на лозі).

Решта сортів — рідкісні українські/молдавські гібриди, яких у вільних базах немає з достовірним підписом. Автопошук за назвою давав **не той об'єкт** (напр. «Молдова» → інший сорт, «Аркадія» → місто, «Флора» → будівля), тому такі результати відкинуто навмисно. У їхніх папках — заглушки, які замініть власними фото.

## Як редагувати дані (назви, ціни, характеристики)
Усі дані зберігаються у масиві `grapes` всередині файлу `index.html` (блок `<script>`).
Кожен сорт — один рядок виду:

```js
{name:"Аркадія", type:"Столовий", color:"Білий", ripen:"Ранній (115–120 дн.)", cluster:"500–2000 г", berry:"7–15 г", taste:"Легкий мускат", frost:"−21 °C"},
```

- `type` — `"Столовий"` або `"Кишмиш"`
- `color` — `"Білий"`, `"Рожевий"`, `"Червоний"` або `"Синій"` (впливає на фільтр і кольорову позначку)

## Примітка
Характеристики (термін дозрівання, маса грона/ягоди, морозостійкість) наведені орієнтовно за усередненими даними. Вони можуть відрізнятися залежно від регіону, ґрунту, догляду та року. За потреби відкоригуйте їх у `index.html`.
